01 / FUNDAMENTALS

What Is HTML?

HTML stands for HyperText Markup Language .

HTML is used to create the structure and content of web pages. It tells the browser what different pieces of content are.

For example, HTML can tell the browser that something is a heading, paragraph, link, image, list or form.

index.html
<h1> My First Website </h1>
<p> Welcome to my website. </p>
02 / FIRST DOCUMENT

Create Your First HTML Document

Create a file called index.html and add the following basic structure.

index.html
<!DOCTYPE html>
<html lang = "en" >
<head>
<title> My Website </title>
</head>
<body>
<h1> Hello World </h1>
</body>
</html>
01

DOCTYPE

Tells the browser that the document uses modern HTML.

02

HTML

The root element that contains the complete HTML document.

03

HEAD

Contains information about the page such as its title and metadata.

04

BODY

Contains the visible content displayed on the web page.

03 / TEXT

Headings & Paragraphs

Use headings to organize your content and paragraphs for normal text.

headings.html
<h1> Main Heading </h1>
<h2> Section Heading </h2>
<h3> Smaller Heading </h3>
<p> This is a paragraph. </p>

HTML provides headings from h1 to h6 . Use them in a logical hierarchy.

04 / LINKS

HTML Links

Links allow users to move from one page or website to another.

links.html
<a href = "https://example.com" > Visit Website </a>

The href attribute tells the browser where the link should go.

05 / IMAGES

HTML Images

Images help communicate information and make websites more visual.

image.html
<img src = "profile.jpg" alt = "My profile photo" >

The src attribute specifies the image location. The alt attribute describes the image.

06 / LISTS

HTML Lists

Lists are useful when displaying multiple related items.

lists.html
<ul>
<li> HTML </li>
<li> CSS </li>
<li> JavaScript </li>
</ul>

Use ul for an unordered list and ol for an ordered list.

07 / BUTTONS

HTML Buttons

Buttons are commonly used for actions and interactions.

button.html
<button> Click Me </button>

A button can later be connected to JavaScript to perform actions when the user clicks it.

08 / FORMS

HTML Forms

Forms allow users to enter information such as names, email addresses and messages.

form.html
<form>
<label> Name </label>
<input type = "text" >
<button type = "submit" > Send </button>
</form>

Forms become much more powerful when combined with CSS, JavaScript and backend development.

09 / STRUCTURE

Semantic HTML

Semantic elements describe the meaning and purpose of different parts of a page.

semantic.html
<header>
Website Header
</header>
<main>
Main Content
</main>
<footer>
Website Footer
</footer>
